# The Deep Sea Portfolio

An immersive one-page portfolio crafted with React, Vite, and Tailwind CSS. Dive through luminescent jellyfish, floating coral projects, an interactive diver mini game, and a message-in-a-bottle contact ritual. The experience supports a midnight-ocean dark mode and ambient sea soundscapes.

## Getting Started

```bash
npm install
npm run dev
```

The development server launches at [http://localhost:5173](http://localhost:5173). Tailwind CSS and Vite hot reloading are already configured.

## Available Scripts

- `npm run dev` – start the local development server
- `npm run build` – create a production build
- `npm run preview` – preview the production build locally
- `npm run lint` – lint the project with ESLint

## Tech & Artistry

- **React 19 + Vite** for a snappy single-page experience
- **Tailwind CSS** with custom keyframes for floating jellyfish, bubbles, and night stars
- **Canvas mini game** where a diver gathers glowing pearls to unlock a secret link
- **Ambient audio toggle** and **Midnight Ocean** dark mode with bioluminescent details

Enjoy the plunge. 🌊
